# 物语的项目变化

## 与原版的关系

本项目基于 Aidoku 开发。iPhone / iPad 源码位于 `Monogatari`，安卓版本位于 `android`，两端分别维护，书库、书架和设置按同一套设计编写。完整功能对应和平台差异见 `android/MIGRATION.md`。

## 名称与标识

- 应用显示为“物语”，英文名和工程名为 Monogatari。
- 安卓包名为 `app.monogatari.android`，代码包同名；iPhone 应用标识为 `app.monogatari.Monogatari`，Xcode 工程、目标、模块和文件夹都改为 Monogatari。
- 两端桌面图标都改为白底粉红色“漫”字，iPhone 的图标由同一张原稿生成。
- 应用自己的链接使用 `monogatari://`。为了继续读取图源生成的链接、旧备份，以及阅读服务登录回调，`aidoku://` 仍然可以打开应用。
- 图源包格式（`.aix`）、图源运行接口、备份格式中的字段名，以及阅读服务登录使用的应用编号，属于和图源、备份文件、第三方服务约定的协议，没有改名。

## 书库

- 两端的书库首页使用相同的布局：横幅轮播、五个快捷入口、三列“为你推荐”、带日榜/周榜/月榜切换的排行榜、两行横向滚动的“热门更新”、单行“新书入库”、三列“完结佳作”和横幅形式的专题。
- 排行榜显示名次、热度和名次升降；热门更新和新书在封面上显示最新章节。
- 分类、完结、新书和热门页面改为三列网格；排行榜页面改为带名次的列表。
- “漫画分类”改为底部面板，所有题材一次显示，同人展标签单独分组。
- iPhone 版新增内置拷贝漫画图源，书库标签直接显示书库首页，右上角可进入图源管理。

## 弹窗

安卓端的选择、筛选和操作类弹窗统一改为底部面板：章节筛选、章节操作、编辑分类、封面、阅读器章节列表和页面操作、阅读设置、字体、设置中的单选与多选、全局搜索筛选、图源筛选、书架筛选组、备份选项、文字识别语言、开始追踪和图片增强模型。确认删除、重命名等需要明确确认的对话框保持不变。

## 书架

书架为空时显示“浏览书库”，点按后进入书库标签。

## 删除的入口

- 两端：iCloud 同步、来源列表管理、Discord 和 Ko-Fi 链接、“关于”页面的编译编号。
- 安卓端：手动迁移旧版本章节阅读记录。

删除来源列表管理时没有清除已有书架、阅读历史或已安装图源。备份格式仍保留旧数据所需字段，以便读取以前保存的备份。

## 图标来源

图标使用内置 imagegen 工具生成，最终原稿保存在 `docs/assets/monogatari-icon.png`。设计要求是：**白色底、粉红色“漫”字、粗体、居中、简洁平面风格，留出桌面图标裁切所需的边距**。
